  • Points 7
  • Submitting a text entry box or a file upload

Challenge 1: Rolodex Card

Build a "card" in index.html to match the above mockup. Code it in HTML and style it with SCSS. Make sure your implementation is responsive. Feel free to make changes to the design as necessary for it to look good on small screens.

Requirements for SCSS:

  • use at least 2 partials imported into the style.scss file (update existing partial files or create new ones)
  • use at least 2 variables
  • use nesting at least twice

Optional Bonus: If you have completed the requirements above and are up for an extra challenge, use color functions and mixins. 

Setup

Begin by creating a new branch for this lesson, off of master branch. Work on this branch for the assignment, and open a pull request from it to master when work is complete.

 

Detailed Instructions:

  • In repo, create a new branch off of master called 'lesson-09' or similar
  • Navigate to the root folder of this assignment within your terminal 
  • Run npm install
  • Run npx gulp
  • Expected output from gulp is information about localhost addresses, and a browser window opening to http://localhost:3000
  • Leave gulp running. As you work with the files, browsersync will watch your scss and HTML files and reload the page in the browser on changes.
  • See mockup image in assignment description for reference
  • Build the component using scss, and follow the requirements found in the assignment description
  • Make sure your implementation is responsive. Feel free to make changes to the design as necessary for it to look good on small screens.

To Submit:

  • Create a Pull Request for your assignment branch to your master branch
  • Submit the link to your pull request in your assignment submission box
